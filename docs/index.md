# Guias de Setup

Bienvenido a las guias de instalacion y configuracion para proyectos Ruby on Rails.

Este sitio centraliza los pasos necesarios para preparar un ambiente de desarrollo, crear un proyecto Rails con PostgreSQL y agregar herramientas comunes del curso.

## Guias disponibles

- [Setup de Ubuntu y WSL](./Ubuntu.md)
- [Setup de macOS con RVM](./MacOs.md)
- [Setup de macOS con rbenv](./rbenv.md)
- [RuboCop](./Rubocop.md)
- [Devise](./Devise.md)
- [Actualizar Rails](./actualizar-rails.md)

## Recomendacion

Si usas Windows, sigue la guia de Ubuntu mediante WSL. Si usas macOS moderno, parte por la guia con `rbenv`.
